# 斩神Ⅱ · 原运营皮肤查询日历

本地入口：`http://127.0.0.1:4173/zhanshen-calendar.html`。与剧集查询模板对照：`calendar-category-compare.html`。

## 定位与结构

日历是查询工具，不承担播放器或手动打卡。原人物主视觉（限高）→ 成长电子票 → 周／月限免日历＋桌面组件入口 → 会员营销。日期查询、切周月、预览票面和组件均不写入观看历史。尚公主默认同样移除日历续看按钮；旧播放交互可用 `purpose=playback` 查看，旧入口对照页冻结为历史模式。

## 皮肤与移动端

新增的 IP 海报小组件视觉与《尚公主》共用 `calendar-poster-widget.*`：日历内缩略图为斩神原画与剧名，大弹窗和桌面效果也同步改成整幅海报。动漫仍只承接排期查询，不依据限免稿虚构可播范围或观看进度。原海报按尺寸分别取景，避开大字标题、播放器与原排期区域；不影响独立的小组件设计稿。

沿用原运营截图的深海军蓝、电光蓝、紫银渐变与机能边框。原截图只作 CSS 取景，文件原样复制到 `dist/assets/zhanshen/`；主视觉从第一张截图 y458 处开始，避开系统条与白色播放器标题栏。日期、集数和规则均为原生 HTML 文本，不把整张海报缩小作为页面。手机393px下主视觉170px，矮屏144px；小屏按实际宽度排版，自然纵向滚动，不整页缩小字号。桌面沿用已使用的 Apple 官方外框资产，画布393×852，外壳453×912。

## 数据边界

截图公布的日期批次：2026-10-29限免2–3集；11-05为4–6集；11-12为7–9集；11-19为10–12集；11-26为13–15集；12-03第2–15集回锁会员。每周四限免更新，但具体钟点、首集权益、VIP／SVIP排播未提供，不补造。日历只展示这些查询事件，不计算累积可播集数，不据此给用户播放授权。12月3日为日期级回锁提示，不宣称零点生效。

默认演示日为11月5日，观看历史示意为1–3集；电子票使用3／9／15集提案门槛，明确并非官方活动规则。仅已解锁初程票能导出PNG，其他票面为灰色上锁预览。没有付款、真实会员提权、系统通知或原生小组件安装。组件预览只展示表情与外观；本页未连接真实跨剧历史，点击演示组件返回查询日历。

## 实现与保留

独立 model/view/controller/CSS 为 `zhanshen-calendar-*`，仅复用既有手机框与通用图标，不改线上页面。两张原截图均保留，不做 AI 重绘。并排页通过独立 iframe 隔离日历状态。原尚公主及其历史播放稿、小组件其他提案与现有本地存储保留。
