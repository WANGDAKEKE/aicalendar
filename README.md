# 追剧日历 Demo

当前汇报版本：v2.3.2（移除重复的下一更与大结局卡片，信息统一回归月历）。

演示地址：https://wangdakeke.github.io/aicalendar/#calendar

## 这一版

- 只展示一个腾讯视频手机界面，删除手机系统日历、锁屏通知和双屏联动。
- 固定顶部录屏与日历标题，主体改为清爽月历；突出今天、更新日与完结日期。
- 根据模拟账户的会员权益选取一个排期，不再并列 SVIP、VIP、非会员三列。
- 删除重复的今日更新摘要，在月份旁展示「VIP 排期」；今天与更新集数直接在月历中查看。
- 点击日期在月历下方展开简洁操作栏，仅保留更新时间、集数和观看按钮，不重复日期、会员说明或勋章条件；支持跨月与回到今天。
- 删除月历下方「下一次更新」「常规大结局」两张汇总卡，更新与完结信息直接在日期格查看；底部仅保留提醒按钮和排期说明。
- 提醒改为一个本机演示开关，不申请手机日历或通知权限，不产生真实通知。
- 保留详情 → 选集 → 日历的点击链路、播放集数高亮及自动观看记录。
- 顶部用一条轻量氛围图合并最近一枚勋章的观看进度，点击查看勋章墙；移除原来的底部重复入口。
- 详情页和选集页的剧集列表下方配置小横图，点击进入日历，收起时返回原来的页面。
- 第 10、18、30 集对应的更新日期保留小勋章标记作为节点提示；勋章进度、故事与解锁条件统一在顶部勋章入口查看。
- 看完前 N 集后自动获得对应勋章，无需额外打卡或领取；获得弹层可直接关闭，也可回日历查看已点亮的标记。
- 少量重点日期在集数下方显示运营小图标，与点映礼共用底部内容区；日期右上角只保留勋章，区分内容提示与个人成就。
- 点击运营日期查看一行看点说明；看点与集数绑定，随当前身份的排期移动。寄语彩蛋及其星标已移除，暂不加入海报解锁或下载。
- 10 月 24 日增加点映礼示例，月历同时保留当天的常规更新集数；展开后显示活动时段、提前看的集数和单独资格说明。点映礼不改变普通会员的可播集数或完结日。

## 运行和校验

无需安装依赖。

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
node --check dist/dual.js
node --test tests/*.test.mjs
```

访问 http://127.0.0.1:4173/#calendar。`main` 推送后，由 GitHub Actions 校验并发布 `dist/` 到 GitHub Pages。

## 演示路径

1. 默认场景：2026 年 10 月 15 日 19:00，VIP，已看完 8 集；今天已更新 9–10 集。
2. 点击 19 日看休更信息；点击月历中金色「完结」的 27 日看完结日安排；上下月切换及“今天”正常可用。
3. 点击有更新且已上线的日期 → “去观看” → 返回详情页，对应集数青绿色高亮。未上线的日期不能播放。
4. 勋章闭环：点顶部「荔枝初程 · 已看 8/10 集」→「继续看第9集」→ 用手机框下方的“快进到第9集结束”及第10集结束，或等待录屏自然播完 → 自动获得「荔枝初程」。当前集数仍由详情页的选集色块表示。
5. 获得后无需领取，直接收入勋章墙；可点「回日历看看」观察 15 日角标变为金色，顶部切换为下一枚「千里同路 · 已看 10/18 集」。关闭弹层保留原页面。
6. 预览「千里同路」「长安赴约」可看条件及进度。已追平后只提供查看更新安排，不允许播放未上线的剧集。跳看第10集但缺第9集不会提前获得，重复观看不会重复弹奖。
7. 刷新保留本机进度和提醒开关；桌面顶部或手机页底部的「重置演示」恢复已看完8集、未获勋章的初始场景。
8. 点击 14 日仅显示更新安排和“再看一遍”，不再出现星标或寄语。
9. 详情页和选集页的横图均可进入日历；点击日历右上角收起按钮，返回进入时的页面。
10. 17、22、23 日的 🤝、💌、🏡 位于集数下方；点击日期查看运营看点示例。切换日期只更新日历内容，不切换上方视频。
11. 点击 24 日的「点映礼」日期格：常规更新仍为 25–26 集；独立活动为 18:00–20:00 提前看 27–30 集，需另行获取资格。默认演示时钟下活动未开始，不提供购买或提前播放入口；常规大结局仍为 27 日。

## 通用框架配置

`dist/drama-config.mjs` 提供剧名、总集数、视频、主题色、勋章与 `scheduleByTier`。勋章可配置 `episode` 门槛、`name`、`story` 文案和 `icon`（lychee / journey / city，其他类型使用 `glyph` 回退）。

每条排期使用 `{date: 'YYYY-MM-DD', time: 'HH:mm', from, to, milestone}`。`milestone` 可为 `premiere`、`finale`。各身份可以拥有独立的播出日期、集数和完结时间；最后一次释放全部集数的日期决定该身份的完结日。

`dist/calendar-model.mjs` 统一计算真实星期、月首偏移、5/6 周月历、跨年切月，以及基于发布时间的“已更新”。当前排期按北京时间解释。

`dist/badge-model.mjs` 按实际看完的剧集集合计算前 N 集进度，并按当前权益排期定位勋章日期；只在首次满足条件时触发获得，不能用最大已看集号代替完整观看记录。

`editorialTheme` 配置共用氛围图、底色和横图入口文案；本次保留这些氛围素材，但移除独立的寄语彩蛋配置与渲染。

`calendarHighlights` 通过 `episode`、`icon` 和 `title` 配置运营看点；图标可使用 emoji，文案示例不代表真实剧情。`screeningEvents` 单独配置活动 `date`、`time`、同日 `endTime`、`from`/`to`、`accessNote`，可选 `tiers` 限制展示身份（不是播放授权）。`dist/operations-model.mjs` 负责按权益映射看点日期、按北京时间计算活动未开始/进行中/已结束状态。活动数据绝不合并到常规排期；同日可同时有更新和活动。

底部内容区默认展示最多两个运营 emoji；同日有点映礼时优先显示活动标签，所有看点和活动仍完整保留在展开区。勋章角标独立渲染，不覆盖运营内容。

`demoSession` 固定演示身份与时钟，便于重复汇报。正式产品需由账号权益接口和服务端时间提供，不可依赖本地存储授权；未知身份降级为非会员排期。观看记录和提醒需接入正式服务。

当前框架面向每天一批常规更新；点映礼只展示独立活动信息，同日多批点映、付费礼包的购买和实际观看授权仍需接入正式权益服务，不能冒充普通会员更新。

## 范围与素材

- 所有日期与会员排期均为示例，不是该剧真实的播出安排。
- 不连接腾讯账号或真实手机日历；没有真实推送、奖励权益或系统授权。
- 顶部及入口主题图复用现有素材；运营看点和点映礼均为演示配置，不代表真实剧情或官方运营活动。
- 视频使用用户提供的录屏素材，公开展示须具有相应权限。
- GitHub Pages 公开可访问，不应放入个人数据或内部机密。
- v1.0.1 双屏版保留在 Git 历史和同名版本标签中。
