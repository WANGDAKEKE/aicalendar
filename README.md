# 追剧日历 Demo

当前汇报版本：v2.6.0（会员排期切换预览、升级提示与轻量月历交互）。

演示地址：https://wangdakeke.github.io/aicalendar/#calendar

## 这一版

- 只展示一个腾讯视频手机界面，删除手机系统日历、锁屏通知和双屏联动。
- 固定顶部录屏与日历标题，主体改为清爽月历；突出今天、更新日与完结日期。
- 月份旁可切换「VIP 排期」「SVIP 排期」「非VIP 排期」，每次进入日历默认恢复账号的真实权益；当前演示账号为 VIP，不再并列三列。
- 切换更高权益时弹出升级提示；关闭或点击「先看看排期」后继续预览。点击升级仅提示未接入会员支付，不购买、不修改身份、不增加实际可播集数。
- 删除重复的今日更新摘要；今天、更新集数与完结日期直接在月历中查看。
- 普通日期点击仅切换选中态，不展开观看操作栏、不启动播放；只有运营看点和点映礼日期可展开对应内容。支持跨月与回到今天。
- 删除月历下方「下一次更新」「常规大结局」两张汇总卡，更新与完结信息直接在日期格查看；底部仅保留提醒按钮和排期说明。
- 提醒是本机演示开关，不申请手机日历或通知权限，不产生真实通知。预览其他权益时显示「按我的 VIP 排期提醒」，点击恢复真实 VIP 排期并开启提醒。
- 保留详情 → 选集 → 日历的点击链路、播放集数高亮及自动观看记录。
- 顶部用一条轻量氛围图合并最近一枚勋章的观看进度，点击查看勋章墙；移除原来的底部重复入口。
- 详情页和选集页的剧集列表下方配置小横图，点击进入日历，收起时返回原来的页面。
- 第 10、18、30 集对应的更新日期保留小勋章标记作为节点提示；勋章进度、故事与解锁条件统一在顶部勋章入口查看。
- 看完前 N 集后自动获得对应勋章，无需额外打卡或领取；获得弹层可直接关闭，也可回日历查看已点亮的标记。
- 少量重点日期在集数下方显示运营小图标，与点映礼共用底部内容区；日期右上角只保留勋章，区分内容提示与个人成就。
- 每格固定日期、集数、内容提示三个槽位，空槽保留空间；数字与集数统一字号和基线，不因图标或活动标签上下跳动。
- 已更新但未看完的日期为浅青绿；该日期所有剧集看完后为浅灰；未来更新为白底浅灰字。「今天」和选中态只加描边，不覆盖观看状态；点映礼与完结仍保留局部金色提示。
- 默认演示跳看：已看 1、2、7、8 集，10、13 日灰色，11、12 日仍为浅青绿。手机框外可切换跳看、14日未看、部分看、已看完四个起点；切换重置该场景，刷新保留当前进度。
- 月历日期始终是更新日，不是实际观看日；不再展示三色图例或灰色待看操作条。播放、补看从详情/选集页的剧集按钮或顶部勋章入口进入；补完只改变对应批次的状态。
- 切换排期预览不会改变观看记录、勋章进度或真实账号权限。默认 VIP 已更新至 12 集，SVIP 预览显示至 14 集，但第 13–14 集不会因此获得播放权限；非VIP 预览也不会降低账号已有的 VIP 权限。
- 开播日期统一为 10 月 10 日；VIP 首更 1–2 集，15 日更新 11–12 集，常规完结仍为 27 日。勋章按实际看过的集数累计，跳到第 8 集不等于已看 8 集。
- 点击运营日期查看一行看点说明；看点与集数绑定，随所预览的排期移动。寄语彩蛋及其星标已移除，暂不加入海报解锁或下载。
- 10 月 24 日增加点映礼示例，月历同时保留当天的常规更新集数；展开后显示活动时段、提前看的集数和单独资格说明。点映礼不改变普通会员的可播集数或完结日。

## 运行和校验

无需安装依赖。

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
node --check dist/dual.js
node --test tests/*.test.mjs
```

访问 http://127.0.0.1:4173/#calendar。`main` 推送后，由 GitHub Actions 校验并发布 `dist/` 到 GitHub Pages。

## 演示路径

1. 默认场景：2026 年 10 月 15 日 19:00，真实账号 VIP，可播至第 12 集，已看完 1、2、7、8 集；10、13 日对应剧集已看完，11、12 日对应剧集仍未看。顶部显示实际进度 4/10，而不是最大已看集号 8/10。
2. 月份旁选择「SVIP 排期」→ 显示升级提示，说明可看至第 14 集、比当前会员多 2 集 → 关闭或点「先看看排期」继续预览。点「升级 SVIP」仅出现演示提示，真实账号仍为 VIP。
3. 选择「非VIP 排期」可直接预览，无需升级；演示时刻该排期更新至第 7 集，但账号实际仍可播放 VIP 已上线的前 12 集。收起后再次进入日历，自动恢复 VIP 排期。
4. 点击普通日期只移动选中边框，不展开待看条、不跳转播放器；27 日金色「完结」标记直接说明常规完结日。上下月切换及「今天」正常可用。
5. 在其他权益预览下点击「按我的 VIP 排期提醒」，恢复真实 VIP 排期并开启本机提醒开关；没有真实日历订阅或推送。
6. 勋章闭环：切换「14日未看」→ 点顶部「荔枝初程 · 已看 8/10 集」→「继续看第9集」→ 用手机框下方的「快进到第9集结束」及第10集结束，或等待录屏自然播完 → 自动获得「荔枝初程」。当前集数仍由详情页的选集色块表示。
7. 获得后无需领取，直接收入勋章墙；可点「回日历看看」观察 VIP 排期中 14 日角标变为金色，顶部切换为下一枚「千里同路 · 已看 10/18 集」。关闭弹层保留原页面。
8. 查看「千里同路」「长安赴约」可了解条件及进度。继续看入口始终按真实账号权益判断；已追平后只提供查看更新安排，不允许借排期预览播放未上线剧集。跳看第10集但缺第9集不会提前获得，重复观看不会重复弹奖。
9. 刷新保留本机进度和提醒开关；桌面顶部或手机页底部的「重置演示」恢复当前场景的初始观看记录。不同场景使用独立的 v3 存储命名空间；排期预览不另建观看历史，不改勋章进度，重新进入日历恢复真实账号排期。
10. 默认跳看场景下，从顶部勋章入口选择「补看第3集」，或到选集页点击第3集；看完第3集后，11 日仍为浅青绿。再补完第4集并返回日历，11 日变灰、12 日仍未看、13 日保持已看，勋章进度为 6/10。补看发生在今天，也不会把 15 日更新的剧集误标成已看。
11. 详情页和选集页的横图均可进入日历；点击日历右上角收起按钮，返回进入时的页面。播放集数从这些页面的选集按钮选择，不通过普通日期跳转。
12. VIP 排期中 16、21、22 日的 🤝、💌、🏡 位于集数下方；点击日期查看「本集看点」，切换会员排期后随对应集数移动。产品内不再显示示例说明，手机框外保留演示数据声明。切换日期只更新日历内容，不切换上方视频。
13. 点击 24 日的「点映礼」日期格：VIP 常规更新仍为 25–26 集；独立活动为 18:00–20:00 提前看 27–30 集，需另行获取资格。默认演示时钟下活动未开始，不提供购买或提前播放入口；VIP 常规大结局仍为 27 日。

## 通用框架配置

`dist/drama-config.mjs` 提供剧名、总集数、视频、主题色、勋章与 `scheduleByTier`。勋章可配置 `episode` 门槛、`name`、`story` 文案和 `icon`（lychee / journey / city，其他类型使用 `glyph` 回退）。

每条排期使用 `{date: 'YYYY-MM-DD', time: 'HH:mm', from, to, milestone}`。`milestone` 可为 `premiere`、`finale`。各身份可以拥有独立的播出日期、集数和完结时间；最后一次释放全部集数的日期决定该身份的完结日。

`dist/calendar-model.mjs` 统一计算真实星期、月首偏移、5/6 周月历、跨年切月，以及基于发布时间的“已更新”。`getReleaseViewingState` 根据当前日期批次的实际已看集合计算未看、部分看、全部看完与下一待看集数；未来批次始终不可播放。当前排期按北京时间解释。

`dist/tier-model.mjs` 提供 `getTierContext(drama, accountTier, previewTier, now)`，分别返回真实账号的 `account`、仅供查看的 `preview` 排期摘要，以及 `requiresUpgrade` 和 `extraAvailable`。权益等级为非VIP、VIP、SVIP；选择更高权益仅触发升级提示，不能据此授予播放权限。非法账号降级为非会员，预览省略或非法时回到账号排期；实际播放、观看记录、勋章继续看入口及提醒始终使用 `account`，月份展示及运营标记使用 `preview`。

`dist/badge-model.mjs` 按实际看完的剧集集合计算前 N 集进度，并根据指定排期定位勋章日期。日历角标随预览排期移动，但点亮状态和勋章墙进度不变；继续看和更新安排使用真实账号排期。只在首次满足条件时触发获得，不能用最大已看集号代替完整观看记录。

`tests/tier-model.test.mjs` 覆盖默认真实身份、升降权益预览、非法值与原型键、配置不可变性及各排期标记独立性；确认 VIP 预览 SVIP 多出的 2 集不会改变真实可播范围。其他测试继续覆盖跳看记录、批次观看状态、勋章解锁和独立点映礼活动。

`editorialTheme` 配置共用氛围图、底色和横图入口文案；本次保留这些氛围素材，但移除独立的寄语彩蛋配置与渲染。

`calendarHighlights` 通过 `episode`、`icon` 和 `title` 配置运营看点；图标可使用 emoji，文案示例不代表真实剧情。`screeningEvents` 单独配置活动 `date`、`time`、同日 `endTime`、`from`/`to`、`accessNote`，可选 `tiers` 限制展示身份（不是播放授权）。`dist/operations-model.mjs` 负责按权益映射看点日期、按北京时间计算活动未开始/进行中/已结束状态。活动数据绝不合并到常规排期；同日可同时有更新和活动。

底部内容区默认展示最多两个运营 emoji；同日有点映礼时优先显示活动标签，所有看点和活动仍完整保留在展开区。勋章角标独立渲染，不覆盖运营内容。

`demoSession` 固定演示身份、时钟和默认场景；`demoScenarios` 通过 `completed` 集数数组提供真实的离散观看记录起点与 `focusDate` 聚焦日期，不使用“最大看到第几集”反推历史。可用 `?scenario=skipped`（默认）、`?scenario=missed`、`?scenario=partial`、`?scenario=caught-up` 直达场景。正式产品需由账号权益接口和服务端时间提供，不可依赖本地存储授权；未知身份降级为非会员排期。观看记录和提醒需接入正式服务。

点映礼公开案例（2026-10-20 查阅）：未找到腾讯统一公开的“倒数第N集显示入口”规则。《梦华录》6月23日公告、6月26日开放33–40集（最后8集），见[中国市场监管报报道](https://finance.sina.com.cn/wm/2022-06-30/doc-imizmscu9505809.shtml)；《三体》2月1日预约、2月3日开放22–30集（最后9集），见[上游新闻实查活动页报道](https://news.cqnews.net/1/detail/1071518173444603904/app/content_1071518173444603904.html)。公开公告时间不等于App入口首次曝光时间，点映范围也不等于已证实的普通VIP更新进度。本demo的24日27–30集是独立演示配置，不是腾讯统一规则；正式接入建议由运营分别配置公告时间、开放时间、集数范围与权益条件。

当前框架面向每天一批常规更新；点映礼只展示独立活动信息，同日多批点映、付费礼包的购买和实际观看授权仍需接入正式权益服务，不能冒充普通会员更新。

## 范围与素材

- 所有日期与会员排期均为示例，不是该剧真实的播出安排。
- 不连接腾讯账号或真实手机日历；没有真实推送、奖励权益或系统授权。升级提示未接入会员支付，点击升级不会改变模拟账号身份。
- 顶部及入口主题图复用现有素材；运营看点和点映礼均为演示配置，不代表真实剧情或官方运营活动。
- 视频使用用户提供的录屏素材，公开展示须具有相应权限。
- GitHub Pages 公开可访问，不应放入个人数据或内部机密。
- v1.0.1 双屏版保留在 Git 历史和同名版本标签中。
